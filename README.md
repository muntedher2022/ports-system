# ⚓ نظام إدارة الموانئ والإيرادات البحرية (Ports System)
> **الشركة العامة لموانئ العراق (GCPI)** — نظام شامل لإدارة العمليات المينائية، حركة الحاويات، تفريغ البضائع، والتحصيل المالي.

---

## 📋 نبذة عن النظام
منظومة متطورة لإدارة وتوثيق حركة الموانئ العراقية تشمل تتبع البضائع العامة، الحاويات، المشتقات النفطية، ومطابقتها مع مراكز الإيرادات السنوية والشهرية، مع سجل تدقيق تفصيلي لكافة العمليات.

## ✨ الميزات الرئيسية
* **إدارة الموانئ (Ports Management):** تعريف الموانئ وأرصفتها وطاقاتها الاستيعابية.
* **حركة ومناولة الحاويات (Container Operations):** تتبع حركات الدخول والخروج والترانزيت وحالات الحاويات.
* **سجلات وتفريغ البضائع (Cargo Handling):** أوزان وحمولات البضائع وحالاتها التفصيلية.
* **مراكز الإيرادات والتحصيل المالي:** تسجيل الإيرادات الشهرية والسنوية ومطابقتها مع الخطط المالية.
* **سجل التدقيق الشامل (Audit Logs):** تتبع دقيق لكافة عمليات التعديل والإدخال مع هوية المستخدم والوقت.
* **تقارير دورية وإحصائية:** تصدير تقارير الحركة والإيرادات بصيغ متعددة.

## 🛠️ التقنيات المستخدمة
* **Framework:** Laravel 11 / Filament v3
* **Language:** PHP 8.4
* **Database:** MySQL
* **Security:** Spatie Laravel Permission
